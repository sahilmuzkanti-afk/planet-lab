# Planet Lab

Planet Lab is an interactive 3D website..
where you can explore the planets and see how physics would work differently on each one,,,,

we made this because we wanted to combine space and  physics  in one project instead of just showing normal planet information.....

You can move through the Solar System,
select a planet,
read about it 
and then enter the Planet Lab to compare different experiments with Earth.

## What you can do

- Explore all 8 planets
- Move between planets using arrow keys or buttons
- See information about each planet
- Compare the gravity of a planet with Earth
- Run different physics experiments
- See the experiments as 3D animations
- Change experiment values and run them again

## Experiments

There are 7 experiments in the Planet Lab:

### Drop Test
Drop an object from a height and compare how long it takes to fall on Earth and the selected planet.

### Jump Test
See how high and how long you could jump with different gravity.

### Throw Test
Throw an object and compare its trajectory, height and distance.

### Weight Test
Enter a mass and see how much it would weigh on Earth and another planet.

### Pendulum Test
Compare how gravity changes the movement and period of a pendulum.

### Launch Test
See how different planets affect the speed needed to escape their gravity.

### Feather vs Hammer
Drop a feather and a hammer and see how gravity and atmosphere affect them.
